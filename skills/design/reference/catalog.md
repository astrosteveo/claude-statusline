# Segment catalog

Generated by `statusline.py segments --markdown`; regenerate with `make catalog`.
Every segment also accepts `format` (template) and `priority` (int).

| segment | priority | what it shows |
|---------|----------|---------------|
| `model` | 100 | Model name, effort level, and the fast-mode flag. |
| `heartbeat` | 99 | A tick that advances every refresh. Each refresh is a fresh process, so the frame comes from the wall clock; a stalled bar freezes on one frame. |
| `dir` | 90 | Working directory, compacted to its last few components. |
| `git` | 85 | Branch, ahead/behind, staged/dirty/untracked counts, stashes, and a nudge when a dirty tree goes stale. |
| `limit_5h` | 80 | The five-hour rate-limit window. |
| `limit_7d` | 75 | The seven-day rate-limit window. |
| `limit_spend` | 72 | The spend-limit window, for accounts behind a gateway that meters spend. |
| `context` | 70 | Context-window usage as a bar, percentage and token count. |
| `pr` | 70 | Pull or merge request number, state and check status, when the host supplies one. |
| `cache` | 65 | The prompt cache, shown only when it is costing money. |
| `worktree` | 62 | The worktree session the host reports (name and branch). |
| `cost` | 60 | Session cost, wall time and lines changed, together. |
| `duration` | 58 | Session wall time on its own. |
| `diff` | 57 | Lines added and removed on their own. |
| `limit_7d_model` | 55 | The per-model weekly window, only when it differs from the overall one. |
| `env` | 50 | Active virtualenv, and the hostname when the session is remote. |
| `host` | 45 | The machine's hostname. |
| `session` | 40 | The session name, when one has been set. |
| `agent` | 38 | The agent name when Claude Code runs with --agent. |
| `vim` | 35 | Vim mode, when vim keybindings are on. Pair with hideVimModeIndicator in settings. |
| `output_style` | 30 | The active output style, unless it is the default. |
| `clock` | 20 | Wall-clock time. |
| `version` | 15 | The Claude Code version the host reports. |
| `text` | 10 | A fixed label. Set `text`, and colour it in `format`. |

## model

Model name, effort level, and the fast-mode flag.

Default format: `<model>{glyph} {name}</model><yellow>{fast}</yellow><dim>[ · {effort}]</dim>`

| option | type | default | meaning |
|--------|------|---------|---------|
| `fast` | bool | `true` | Show the fast-mode glyph when fast mode is on. |

| field | holds |
|-------|-------|
| `{glyph}` | the model glyph |
| `{name}` | display name or id |
| `{fast}` | fast-mode glyph, or empty |
| `{effort}` | effort level, 'think', or empty |

## heartbeat

A tick that advances every refresh. Each refresh is a fresh process, so the frame comes from the wall clock; a stalled bar freezes on one frame.

Default format: `<tick>{frame}</tick>`

| option | type | default | meaning |
|--------|------|---------|---------|
| `frames` | str | `""` | One glyph per frame; empty means [glyphs].heartbeat_frames. |
| `period` | float | `1.0` | Seconds per frame; match refreshInterval. |
| `color` | str | `"dim"` | A [colors] key for the tick. |

| field | holds |
|-------|-------|
| `{frame}` | the current frame |

| colour | when |
|--------|------|
| `<tick>` | the configured `color` |

## dir

Working directory, compacted to its last few components.

Default format: `<dir>{glyph} {path}</dir>`

| option | type | default | meaning |
|--------|------|---------|---------|
| `depth` | int | `3` | Trailing path components to keep. |

| field | holds |
|-------|-------|
| `{glyph}` | the directory glyph |
| `{path}` | compacted path |
| `{full}` | the whole path with ~ for home |
| `{base}` | last component only |

## git

Branch, ahead/behind, staged/dirty/untracked counts, stashes, and a nudge when a dirty tree goes stale.

Default format: `<dim>{glyph} </dim><link><gitstate>{branch}</gitstate></link>[ <red>{state}</red>][ <cyan>{ahead}</cyan>][ <cyan>{behind}</cyan>][ <dim>{noupstream}</dim>][ <green>{staged}</green>][ <yellow>{dirty}</yellow>][ <gray>{untracked}</gray>][ <red>{conflict}</red>][ <gray>{stash}</gray>][ <agecolor>{age}</agecolor>][ <dim>{wt}</dim>]`

| option | type | default | meaning |
|--------|------|---------|---------|
| `links` | bool | `true` | OSC-8 hyperlink on the branch when the host names the repo. |
| `last_commit` | bool | `true` | Read the last commit time (one more git call when dirty). |
| `nudge_min` | int | `45` | Minutes since the last commit before `age` appears on a dirty tree. |

| field | holds |
|-------|-------|
| `{glyph}` | the git glyph |
| `{branch}` | branch, @sha when detached |
| `{url}` | branch URL |
| `{state}` | REBASE, MERGE, CHERRY-PICK, REVERT or BISECT |
| `{ahead}` | ↑n |
| `{behind}` | ↓n |
| `{noupstream}` | ∅ when the branch has no upstream |
| `{staged}` | +n |
| `{dirty}` | ~n |
| `{untracked}` | ?n |
| `{conflict}` | !n |
| `{stash}` | ⚑n |
| `{age}` | ⏱ time since last commit, once a dirty tree goes stale |
| `{wt}` | 'wt' inside a linked worktree |

| colour | when |
|--------|------|
| `<gitstate>` | green when clean, orange when dirty |
| `<agecolor>` | gray, then yellow past 2h, orange past 4h |

## limit_5h

The five-hour rate-limit window.

Default format: `<gray>{label}</gray>[ {bar}] <level>{pct}%</level>[ <pacecolor>{pace}</pacecolor>][ <dim>{reset}[·{clock}]</dim>]`

| option | type | default | meaning |
|--------|------|---------|---------|
| `width` | int | `-1` | Bar cells; -1 means [bar].width. |
| `pace` | bool | `true` | Project end-of-window usage from the burn rate. |
| `pace_min_elapsed` | float | `0.1` | Do not extrapolate from under this fraction of the window. |
| `clock` | bool | `true` | Append the wall-clock time of the reset. |
| `missing` | str | `"<dim>{label} —</dim>"` | Template used when the host sends no such window; empty hides it. |

| field | holds |
|-------|-------|
| `{label}` | the window label |
| `{bar}` | the bar |
| `{pct}` | whole-number percentage |
| `{pace}` | ⇢ projected usage at reset |
| `{reset}` | ↻ time until reset |
| `{clock}` | wall-clock time of the reset |

| colour | when |
|--------|------|
| `<level>` | green / yellow / orange / red by [thresholds] |
| `<pacecolor>` | red when the projection exceeds 100%, orange past 85%, else dim |

## context

Context-window usage as a bar, percentage and token count.

Default format: `<gray>{label}</gray>[ {bar}] <level>{pct}%</level>[ <dim>({detail})</dim>]`

| option | type | default | meaning |
|--------|------|---------|---------|
| `label` | str | `"ctx"` | Label before the bar. |
| `width` | int | `-1` | Bar cells; -1 means [bar].width. |
| `tokens` | bool | `true` | Show the token count beside the percentage. |
| `size` | bool | `true` | ...and the window size, e.g. (380k/1.0M). |

| field | holds |
|-------|-------|
| `{label}` | the label |
| `{bar}` | the bar |
| `{pct}` | whole-number percentage |
| `{tokens}` | tokens used, short form |
| `{size}` | window size, short form |
| `{detail}` | tokens, or tokens/size |

| colour | when |
|--------|------|
| `<level>` | green / yellow / orange / red by [thresholds] |

## pr

Pull or merge request number, state and check status, when the host supplies one.

Default format: `<link><prstate>{glyph} {sigil}{number}[ {checks}]</prstate></link>`

| option | type | default | meaning |
|--------|------|---------|---------|
| `links` | bool | `true` | OSC-8 hyperlink to the PR. |

| field | holds |
|-------|-------|
| `{glyph}` | the PR glyph |
| `{sigil}` | # for GitHub, ! for GitLab |
| `{number}` | PR number |
| `{state}` | open, draft, merged, closed, or the review state |
| `{checks}` | ✓ ✗ or ● for the check status |
| `{kind}` | github or gitlab |
| `{url}` | PR URL |

| colour | when |
|--------|------|
| `<prstate>` | green open/approved, gray draft, purple merged, red closed, orange changes requested, yellow awaiting review |

## cache

The prompt cache, shown only when it is costing money.

Default format: `<cachestate>{glyph} {detail}</cachestate>`

| option | type | default | meaning |
|--------|------|---------|---------|
| `min_ratio` | float | `0.9` | Warn when the hit ratio falls below this. |

| field | holds |
|-------|-------|
| `{glyph}` | the cache glyph |
| `{detail}` | 'cold <tokens>' or '<ratio>%' |
| `{ratio}` | hit ratio as a percentage |
| `{tokens}` | tokens to recache if cold |

| colour | when |
|--------|------|
| `<cachestate>` | orange when cold, yellow when the ratio is low |
