# Segment catalog

Generated by `statusline.py segments --markdown`; regenerate with `make catalog`.
Every segment also takes `format` (its body template), `priority`, `icon` ("" hides it) and `color` (the theme role its icon and chip wear).

| segment | priority | what it shows |
|---------|----------|---------------|
| `model` | 100 | The model, its effort level, and the fast-mode flag. |
| `heartbeat` | 99 | A debugging aid, off unless placed: a tick that moves on every refresh. The frame comes from the clock, so a bar that has stopped refreshing freezes on one frame. |
| `dir` | 90 | The working directory: parents abbreviated, the folder you are in picked out. |
| `git` | 85 | Branch, ahead/behind, staged/modified/untracked counts, stashes, conflicts, and a nudge when a dirty tree has gone a while without a commit. |
| `limit_5h` | 80 | The five-hour rate-limit window, with a pace projection and the reset countdown. |
| `limit_7d` | 75 | The seven-day rate-limit window. |
| `limit_spend` | 72 | The spend limit, for accounts behind a gateway that meters spend. |
| `context` | 70 | How full the context window is: a bar, the percentage, and the tokens. |
| `pr` | 70 | The pull or merge request for this branch, its review state and checks. |
| `mode` | 66 | The permission mode when it is not the default: plan, accept edits, auto, don't ask or bypass (live activity; the hooks see it change on the next event). |
| `cache` | 65 | The prompt cache, shown only while it is costing you: cold, or missing too often. |
| `worktree` | 62 | The worktree this session runs in, and its branch. |
| `cost` | 60 | What the session has cost, with its wall time and lines changed alongside. |
| `duration` | 58 | The session's wall time, and how much of it was spent waiting on the API. |
| `diff` | 57 | Lines added and removed this session. |
| `spend` | 56 | What today cost across every session this bar has drawn (local days), with the week and the month, and an optional daily budget drawn as a bar. |
| `limit_7d_model` | 55 | The per-model weekly window, shown only when it differs from the overall one. |
| `turn` | 52 | How long Claude has been working on your last message, or how long it has waited for you since it finished; compaction and a failed turn too (live activity). |
| `env` | 50 | The active virtualenv or conda env, and the host when the session is remote. |
| `tools` | 48 | The tools Claude is running now, with what they work on and for how long, then the ones just finished this turn (live activity). |
| `agents` | 47 | The subagents at work: their kind, what they were asked, and for how long (live activity). |
| `burn` | 45 | The spend rate: dollars per hour of session so far. |
| `host` | 45 | The machine's name (only over SSH or in a container, unless `always`). |

| `session` | 40 | The session name, once one is set (/rename). |

| `quest_boss` | 60 | The boss you are fighting: a failing test, build or lint run, with its HP as hearts. (Claude Quest) |
| `quest_event` | 50 | The latest thing that happened (loot, a level-up, a quest done), for a little while. (Claude Quest) |

| `quest` | 42 | Your Claude Quest hero: level, title, class, and progress to the next level. (Claude Quest) |
| `quest_raid` | 40 | This week's tech-debt raid boss in this project: its HP is the TODO/FIXME/XXX/HACK markers, counted at each commit. (Claude Quest) |
| `quest_daily` | 36 | Today's quests done out of three, and the weekly quest's progress. (Claude Quest) |
| `quest_gold` | 30 | Claude Quest gold, and the items in your bag. (Claude Quest) |
| `quest_streak` | 26 | Days in a row you have played (from two days on). (Claude Quest) |

## model

The model, its effort level, and the fast-mode flag.

Tone: `model`. Default format: `<model><bold>{name}</bold></model>[ <yellow>{fast}</yellow>][<muted> · {effort}</muted>]`

| option | type | default | meaning |
|--------|------|---------|---------|
| `fast` | bool | `true` | Show the fast-mode mark when fast mode is on. |
| `full_name` | bool | `false` | Keep the qualifier the host adds, e.g. (1M context). |

| field | holds |
|-------|-------|
| `{name}` | the model name (without the qualifier unless full_name) |
| `{full}` | the display name as the host sends it |
| `{short}` | the name without its qualifier |
| `{id}` | the model id |
| `{fast}` | the fast-mode mark, or empty |
| `{effort}` | effort level, 'think', or empty |

## heartbeat

A debugging aid, off unless placed: a tick that moves on every refresh. The frame comes from the clock, so a bar that has stopped refreshing freezes on one frame.

Tone: `muted`. Default format: `<tick>{frame}</tick>`

| option | type | default | meaning |
|--------|------|---------|---------|
| `frames` | str | `"dots"` | A named set (dots, orbit, quadrants, arc, wave, pulse, bounce, line, moon, grow, star) or a string of one-cell glyphs. |
| `period` | float | `1.0` | Seconds per frame; match refreshInterval. |

| field | holds |
|-------|-------|
| `{frame}` | the current frame |

| colour | when |
|--------|------|
| `<tick>` | the configured `color` |

## dir

The working directory: parents abbreviated, the folder you are in picked out.

Tone: `dir`. Default format: `<muted>{parent}</muted><dir><bold>{base}</bold></dir>`

| option | type | default | meaning |
|--------|------|---------|---------|
| `mode` | str | `"fish"` | fish (~/P/project), compact (…/a/b/project), full, base, or project (relative to the project root) One of: fish, compact, full, base, project. |
| `depth` | int | `1` | Trailing components kept whole (fish, compact). |

| field | holds |
|-------|-------|
| `{path}` | the whole display path |
| `{parent}` | everything before the last component |
| `{base}` | the last component |
| `{full}` | the full path with ~ for home |
| `{project}` | the project's folder name |

## git

Branch, ahead/behind, staged/modified/untracked counts, stashes, conflicts, and a nudge when a dirty tree has gone a while without a commit.

Tone: `green`. Default format: `<link><gitstate><bold>{branch}</bold></gitstate></link>[ <red><bold>{state}</bold></red>][ <cyan>{sync}</cyan>][ <muted>{noupstream}</muted>][ <green>{staged}</green>][ <yellow>{dirty}</yellow>][ <subtext>{untracked}</subtext>][ <red>{conflict}</red>][ <subtext>{stash}</subtext>][ <agecolor>{age}</agecolor>]`

| option | type | default | meaning |
|--------|------|---------|---------|
| `links` | bool | `true` | Make the branch a link when the host names the repository. |
| `last_commit` | bool | `true` | Read the last commit's time, for the {age} nudge. |
| `nudge_min` | int | `45` | Minutes without a commit before {age} appears on a dirty tree. |
| `max_branch` | int | `32` | Longest branch name shown; longer ones end in … |

| field | holds |
|-------|-------|
| `{branch}` | the branch, or @sha when detached |
| `{url}` | the branch's web URL |
| `{state}` | REBASE, MERGE, CHERRY-PICK, REVERT or BISECT |
| `{sync}` | ⇡ahead ⇣behind |
| `{ahead}` | commits ahead |
| `{behind}` | commits behind |
| `{noupstream}` | ∅ when the branch has no upstream |
| `{staged}` | +staged |
| `{dirty}` | ~modified |
| `{untracked}` | ?untracked |
| `{conflict}` | !conflicted |
| `{stash}` | stash count |
| `{age}` | time since the last commit, once a dirty tree goes stale |
| `{changes}` | all local changes as one count |
| `{clean}` | ✓ when nothing is changed |

| colour | when |
|--------|------|
| `<gitstate>` | green when clean, orange with changes, red with conflicts |
| `<agecolor>` | subtext, yellow past 2h, orange past 4h |

## limit_5h

The five-hour rate-limit window, with a pace projection and the reset countdown.

Tone: `green`. Default format: `[<subtext>{label}</subtext> ][{bar} ]<level><bold>{pct}%</bold></level>[ <pacecolor>{pace}</pacecolor>][ <muted>{reset}[·{clock}]</muted>]`

| option | type | default | meaning |
|--------|------|---------|---------|
| `label` | str | `"5h"` | Label before the bar; empty for none. |
| `width` | int | `-1` | Bar cells; -1 means [bar].width. |
| `style` | str | `""` | Bar style for this segment; empty means [bar].style. |
| `fill` | str | `""` | Bar fill for this segment; empty means [bar].fill. |
| `pace` | bool | `true` | Project where usage will be when the window resets (⇢). |
| `pace_mode` | str | `"recent"` | recent: the rate over the last stretch of the window; average: usage so far over the window gone. One of: recent, average. |
| `pace_min_elapsed` | float | `0.1` | Don't extrapolate an average from under this much of the window. |
| `pace_lookback` | float | `0.1` | The stretch `recent` measures, as a fraction of the window. |
| `reset` | bool | `true` | Show the time until the window resets (↻). |
| `clock` | bool | `true` | ...and the time of day it resets. |
| `missing` | str | `"<muted>{label} —</muted>"` | Shown when the host sends no such window; empty hides the segment. |

| field | holds |
|-------|-------|
| `{label}` | the window's label |
| `{bar}` | the bar |
| `{pct}` | whole percentage |
| `{pace}` | ⇢ projected usage at reset |
| `{reset}` | ↻ time until reset |
| `{clock}` | time of day of the reset |
| `{left}` | percentage left |

| colour | when |
|--------|------|
| `<level>` | green / yellow / orange / red by [thresholds] |
| `<pacecolor>` | red when the projection passes 100%, orange past 85%, else muted |

Tone: `orange`. Default format: `<orange>${rate}</orange><muted>/h</muted>`

| option | type | default | meaning |
|--------|------|---------|---------|
| `min_minutes` | float | `5.0` | Wait this long into a session before showing a rate. |

| field | holds |
|-------|-------|
| `{rate}` | dollars per hour |

## host

The machine's name (only over SSH or in a container, unless `always`).

Tone: `teal`. Default format: `<teal>{host}</teal>`

| option | type | default | meaning |
|--------|------|---------|---------|
| `always` | bool | `false` | Show it on the local machine too. |
| `user` | bool | `false` | Prefix the user name. |

| field | holds |
|-------|-------|
| `{host}` | hostname |
| `{user}` | user name |

## tasks

The task list Claude keeps (TaskCreate or TodoWrite, where the model has them): the task in hand and how many are done (live activity).

Tone: `green`. Default format: `[<text>{current}</text> ]<bold>{done}/{total}</bold>`

| option | type | default | meaning |
|--------|------|---------|---------|
| `max` | int | `32` | Longest task title shown. |

| field | holds |
|-------|-------|
| `{current}` | the task in progress (or the next one) |
| `{done}` | tasks completed |
| `{total}` | tasks in the list |

## quest_dungeon

The PR dungeon of this project: opened by `gh pr create`, a room per push, a trap when checks fail, cleared by merging.

Tone: `purple`. Default format: `<purple><bold>#{number}</bold></purple>[ <muted>{name}</muted>] <subtext>{rooms}</subtext>[ {trap}]`

| field | holds |
|-------|-------|
| `{number}` | the pull request's number |
| `{name}` | the dungeon's name (dropped when narrow) |
| `{rooms}` | rooms so far, one per push |
| `{traps}` | traps sprung by failing checks |
| `{trap}` | a warning while checks are failing |
| `{project}` | the project |

## quest

Your Claude Quest hero: level, title, class, and progress to the next level.

Tone: `gold`. Default format: `<gold><bold>Lv {level}</bold></gold>[ <purple>{title}</purple>][ {class_icon}][ {bar}][ <muted>{xp}/{need}</muted>]`

| option | type | default | meaning |
|--------|------|---------|---------|
| `width` | int | `10` | XP bar cells; 0 hides the bar. |
| `fill` | str | `"cyan,purple"` | XP bar fill: colour roles blended along it, or level/gradient. |
| `style` | str | `""` | Bar style; empty means [bar].style. |

| field | holds |
|-------|-------|
| `{level}` | hero level |
| `{title}` | your title (or rank) |
| `{rank}` | rank for the level |
| `{class_icon}` | your class's emoji |
| `{class}` | your class |
| `{bar}` | XP progress bar |
| `{xp}` | XP into this level |
| `{need}` | XP this level takes |
| `{pct}` | percent to next level |
| `{gold}` | gold carried |
| `{bag}` | items carried |

## quest_pet

Your companion as a little text sprite strolling across a yard. It evolves with your level, hurries while tools run, cheers at loot and level-ups, and dozes when you step away. Hidden while the kitty picture of it is on screen.

Tone: `green`. Default format: `<petc>{yard}</petc>`

| option | type | default | meaning |
|--------|------|---------|---------|
| `yard` | int | `24` | Columns the pet roams; halves when the line is narrow. |
| `excited` | float | `20.0` | Seconds the pet celebrates after an event. |
| `sleepy` | float | `600.0` | Idle seconds before it falls asleep. |

| field | holds |
|-------|-------|
| `{yard}` | the pet at its spot in the yard |
| `{sprite}` | the pet alone |
| `{mood}` | excited, working, idle or sleepy |
| `{stage}` | egg … wyrm |
| `{form}` | a drake's or wyrm's form: ember, forge, lore, arcane or storm |

| colour | when |
|--------|------|
| `<petc>` | green; gold while excited, muted asleep |
